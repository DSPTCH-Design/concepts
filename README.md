# DSPTCH Concepts

Concept websites by DSPTCH Design. Each folder is a standalone static site deployed as its own Netlify project.

| Folder | Site |
|---|---|
| `qubik/` | QUBIK Architecture + Engineering |
| `arena/` | ARENA Men's Health |
| `davyn/` | DAVYN Dental Studio |
| `vela/` | VELA Aesthetics |
| `alden-mercer/` | Alden & Mercer |
| `xenro/` | XENRO Logistics |

Each site uses plain HTML, CSS and vanilla JS with no build step. In Netlify, set the base and publish directory to the site's folder.
